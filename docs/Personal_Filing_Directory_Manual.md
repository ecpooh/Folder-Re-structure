Raw system files that belong to the filing folder itself (not content to file elsewhere). Examples: Readme, Thumbnail, and similar folder-meta files.

## S — Special Event

Permanent, memorable, kept forever. Major life milestones (e.g. house buying, marriage). Not for routine travel — see A5.

## T — Temporary

Short-lived use only (file transfers, testing files). Not expected to be kept for more than a few days.

## U — Unsorted

Temporary holding pen. Organized monthly; 1-year maximum residency before it must be sorted into a real category.

## Key Boundary Rules (Quick Reference)

- **S vs X vs T:** permanence — S = forever, X = deleted after the project/event ends, T = deleted within days
- **A2 vs F vs G4:** A2 = active work project (even with $ inside), F = personal-only $ items, G4 = company docs without an active project
- **F vs H2:** F = personal-only finance, H2 = shared/household finance
- **A1 vs A3 vs A4:** A1 = soft-skill development, A3 = technical knowledge, A4 = exam materials (either)
- **A5 vs S:** A5 = all travel, S = major life milestones only
- **D vs E:** D = non-game software only
- **G vs B/C:** G = info about a person/pet, never photos (those stay in B/C)
- **C21:** animation you watch, not animation you create (→ K)
- **R:** folder-meta / system files for the filing structure itself (Readme, Thumbnail, etc.), not ordinary content
